# Relay

An original AI automation SaaS website and product concept. Warm ivory, electric cobalt, an original mathematical wireframe sculpture, and an interactive workflow workspace. Built with dependency-free HTML, CSS, and JavaScript.

## Run

```bash
npm run dev
```

Open http://localhost:4175. Set `PORT` to use another port.

```bash
npm run check
npm run build
```

The build copies the static website into `dist/`. Serve that directory on any static host.

## Interactions

- Three simulated workflows, each with staged execution, distinct sample output, and human approval.
- Workflow starter modal opened from navigation, pricing, or the closing CTA.
- Monthly and annual concept pricing; the billing preference is stored locally.
- Keyboard-accessible workflow tabs, mobile navigation, native dialogs, FAQ, and reduced-motion support.
- Self-hosted fonts and original procedural SVG artwork. No runtime dependencies or third-party requests.

This is a fictional product, not a connected AI service. Integrations and pricing illustrate a product idea. No account, real email, payment, or live app action is created.

The orbital illustration can be regenerated with `node scripts/generate-orbit.mjs`.
